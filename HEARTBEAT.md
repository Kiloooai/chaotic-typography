# Autonomous Build — Every 90 minutes

## 🎲 MISSION: ORIGINAL, FUN, COOL STUFF YOU'D ACTUALLY USE

Every 90 minutes, build something **original, entertaining, or unexpectedly useful**. No business products, no productivity grinders, no automation scripts. Think: fun, weird, clever, or genuinely cool.

## What to Build

- ** browser toys & experiments** — visual, interactive, playful
- ** tiny games** — original mechanics, not clones
- ** weird generators** — e.g., "cosmic microwave background noise generator"
- ** retro/weird UI experiments** — Y2K aesthetic, glitch art controllers
- ** personal data visualizations** — "your typing rhythm analyzer"
- **prank/dev tools with a smile** — e.g. "terminal typo detector that roasts you"
- ** audio/music gizmos** — browser synths, weird sound mixers
- **"I built this because it amused me"** projects

**NOT allowed:**
- ❌ Business SaaS / sellable products
- ❌ Automation / scripting tools
- ❌ Todo apps / productivity trackers
- ❌ Generic landing pages
- ❌ Things you'd find in "top 10 beginner projects"

## Vibe Check

If it makes you smile when you open it, or you show it to a friend going "look at this weird thing I made", it's on target.

## Build Process

1. Pick something **unusual, fun, or visually engaging**
2. Code it fully (no placeholders)
3. Git + push to a remote (type-appropriate repo visibility) — **MANDATORY**
4. Log it, update rotation

## Rotation

Kept for bookkeeping (Type 0 Python builds are encouraged too — don't HTML-only):
- Type 0: Python CLI / tiny tool → private
- Type 1: SaaS landing → SKIP
- Type 2: Python automation → private
- Type 3: Dashboard / web app / browser toy → public + Pages

Type 3 now means "interactive fun" (not business dashboards).

## Golden Rule

**Fun first.** If you're not slightly amused by the end result, pick a different idea.
